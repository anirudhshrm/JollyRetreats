                      USER FLOW SUMMARY
═══════════════════════════════════════════════════════════════════

1. User makes booking (property, tour, or service)
   ↓
2. User provides/confirms email address
   ↓
3. User clicks "Confirm Reservation/Booking"
   ↓
4. Booking created in database ✅
   ↓
5. Email extracted from request
   ↓
6. Invoice PDF generated
   ↓
7. Email sent via Gmail SMTP
   ↓
8. Confirmation page shown to user ✅
   ↓
9. Email arrives in inbox (1-2 minutes)
   ↓
10. User receives complete booking confirmation
